# Code of Conduct

This project aims to be a useful, technically serious, and welcoming open-source space.

## Expected behavior

Participants should:

- discuss ideas and code on their technical merits;
- be specific and constructive when reviewing work;
- respect different levels of experience and different viewpoints;
- avoid harassment, insults, threats, discriminatory language, and personal attacks;
- protect private information and never post customer or employer data without authorization;
- accept maintainer decisions about project scope while remaining free to disagree respectfully.

## Unacceptable behavior

Harassment, intimidation, doxxing, sexualized attention, discriminatory conduct, spam, deliberate disruption, or repeated bad-faith interaction may result in content removal or loss of participation privileges.

## Enforcement

Report conduct concerns privately to the repository maintainer rather than escalating them publicly. Maintainers may edit or remove content, close threads, lock conversations, or restrict participation when necessary to protect the project and its contributors.

Project technical criticism is welcome; personal attacks are not.
