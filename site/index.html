03

برای چه مدل‌هایی مناسب است؟

از گزارش ساده تا مدل ستاره‌ای چند Fact.

مدل ساده

Sales[SaleDate] را مستقیم بده.

Star Schema

ترجیحاً DimDate[Date] را به Picker متصل کن.

DateTime

تمام timestampهای همان روز با بازه‌ی کامل روز پوشش داده می‌شوند.

DirectQuery

Visual فقط Filter می‌دهد؛ Query execution تابع مدل و Source است.

RLS

Picker امنیت را دور نمی‌زند و فقط داده قابل مشاهده را محدودتر می‌کند.

Bookmarks

انتخاب از Power BI Filter State بازیابی می‌شود.
