# Roadmap

This roadmap communicates direction, not a promise of delivery dates.

## Stable foundation

- [x] Single-day Persian/Jalali picker.
- [x] Gregorian Date/DateTime native filtering.
- [x] Whole-day half-open interval semantics.
- [x] Bookmark/filter restoration.
- [x] Runtime type validation.
- [x] Clear-filter action.
- [x] CI packaging and downloadable PBIVIZ.
- [x] Production dependency audit and CodeQL.
- [x] Professional documentation and GitHub Pages.
- [x] Upstream tracking strategy.

## Candidate next features

- [ ] Date range selection with explicit inclusive/exclusive semantics.
- [ ] Formatting options compatible with Power BI formatting pane.
- [ ] Theme/high-contrast refinements.
- [ ] More deterministic calendar boundary tests.
- [ ] Automated accessibility checks.
- [ ] Signed/tagged release process with checksums.
- [ ] Organizational/AppSource distribution investigation.
- [ ] Localization beyond the primary Persian UI where useful.

## Explicitly deferred

- External conversion APIs.
- Telemetry requiring web privileges.
- Parsing arbitrary Persian date text columns.
- Hidden mutation of model data.

Large roadmap items need a design update/ADR before implementation.
