# Threat Model

## Scope

This threat model covers the Power BI custom visual under `powerbi/`, its packaged PBIVIZ, and the CI/release pipeline.

## Assets

- integrity of report filtering;
- confidentiality of report/model data exposed to the visual host;
- integrity of the distributed PBIVIZ;
- repository and CI credentials;
- user trust in Jalali/Gregorian conversion.

## Trust boundaries

```text
User interaction
      │
      ▼
Power BI visual sandbox
      │
      ├── Power BI host APIs
      │       └── report filter state
      │
      └── bundled local dependencies

GitHub repository
      │
      ▼
GitHub Actions
      │
      ▼
release/PersianDatePicker.pbiviz
```

## Main threats and controls

### Data exfiltration

**Threat:** report data is transmitted to an external service.

**Controls:** no web-access privilege; no telemetry; no external API calls; no AAD privilege.

### Persistent data capture

**Threat:** model/user data is stored locally for later access.

**Controls:** no storage privilege; no local-storage requirement; selection is restored from Power BI's own filter state.

### HTML/script injection

**Threat:** untrusted values become executable DOM content.

**Controls:** native DOM creation/text content; avoid `innerHTML`; no dynamic code evaluation.

### Filter target confusion

**Threat:** bookmark restoration displays a date from an unrelated advanced filter.

**Controls:** restored filters must match the currently bound table and column target.

### Date boundary integrity

**Threat:** timezone/off-by-one errors cause records from the wrong day to appear.

**Controls:** explicit conversion tests and half-open UTC day intervals.

### Dependency compromise

**Threat:** vulnerable/compromised runtime dependency enters the PBIVIZ.

**Controls:** minimal dependencies, production npm audit, CodeQL, package build, review of dependency changes.

### CI artifact tampering

**Threat:** a package not built from reviewed `master` is published as canonical.

**Controls:** release artifact is generated by GitHub Actions after code reaches `master`; CI gates package creation; repository history records the publication commit.

## Residual risks

- Power BI host/platform behavior can change independently.
- Semantic timezone interpretation can vary between datasets; v1 explicitly defines UTC-boundary semantics.
- The underlying upstream dependency may receive security or correctness updates that require controlled integration.

## Security review triggers

Revisit this model when adding network access, telemetry, storage, authentication, export, range selection with new state semantics, custom-domain assets, or a new release/distribution channel.
